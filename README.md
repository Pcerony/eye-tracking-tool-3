# Browser Eye Tracking Tool

A static browser-based eye tracking experiment tool powered by WebGazer.js.

## Features

- 9-point camera calibration with mouse or keyboard confirmation
- Participant ID input
- Up to five preloaded stimulus images
- Multi-image tracking sessions under one calibration
- Heatmap, gaze path, and CSV export
- Participant archive import and export
